# Changelog

## 0.11.1

Fehlerbehebungen UI

## 0.11.0

Generator-Parameter dürfen statt eines festen Werts andere Spalten derselben
Tabelle als `{spalte}` referenzieren.

## 0.10.0

Eigene Seitenleiste bietet fünf Ansichten für Projekte, Schema, Nachschlagelisten und Generatoren.

## 0.9.0

Eigene Dateigeneratoren (`.filegen`) schreiben die Ausgabedatei komplett selbst,
Dateityp „Temporäre Tabelle“ generiert Datensätze direkt, ohne eine physische Datei anzulegen.
Führende Nachschlagelistn steuern die Tabellen so, dass pro Listenzeile exakt ein Datensatz entsteht.

## 0.8.0

Neuer Dateityp „Feste Satzlänge“ mit Konfiguration für Spalte, Startposition, Breite, Ausrichtung und Füllzeichen.

## 0.7.0

Neue Ausgabeformate für Excel, JSON und XML.
